# 1602 ВКГ — React + TypeScript + Vite

## Запуск

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Проект построен на React + TypeScript + Vite. Интерактивные элементы главной страницы реализованы через React state/events, без imperative DOM-кода.
